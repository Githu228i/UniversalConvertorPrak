# Universal Number System Converter

Конвертер чисел между системами счисления от **2 до 500** с поддержкой:

- целых чисел
- дробных чисел
- периодических дробей
- длинной арифметики

Проект написан на **C++** с использованием **Qt**.

---

# Возможности

## Поддерживаемые системы счисления

- от **2** до **500**

---

## Поддерживаемые типы чисел

### Целые числа

```txt
101101
```

### Дробные числа

```txt
101.101
```

### Периодические дроби

```txt
0.(3)
12.1(45)
```

---

# Представление цифр

## Основания ≤ 36

Используются стандартные символы:

```txt
0-9 A-Z
```

---

## Основания > 36

Цифры записываются в квадратных скобках:

```txt
[36][57][499]
```

---

# Компоненты проекта

## BigInteger

Класс длинной арифметики.

Поддерживает:
- сложение
- вычитание
- умножение
- деление
- остаток
- сравнение

Числа хранятся во внутреннем виде как `vector<int>` по основанию `10^9`.

---

## BigFraction

Класс рациональных чисел произвольной точности.

Поддерживает:
- арифметические операции
- сокращение дробей
- выделение целой части
- получение остатка

---

## BaseParser

Переводит число из p-ичной системы счисления в десятичную рациональную дробь.

Поддерживает:
- дробную часть
- периодические дроби
- большие основания

---

## BaseFormatter

Переводит число из десятичной формы в q-ичную систему счисления.

Поддерживает:
- периодические дроби
- большие основания
- вывод цифр в формате `[число]`

---

## DigitTokenizer

Нормализует ввод пользователя.

Функции:
- заменяет одиночные символы на формат `[число]`
- переводит буквы в числовые значения
- подготавливает строку к обработке парсером

Пример:

```txt
A1F -> [10][1][15]
```

---

## InputValidator

Проверяет корректность ввода.

Проверяет:
- допустимость цифр для основания
- корректность скобок
- формат дробной части
- корректность периода

---

## BaseConverter

Фасад программы.

Объединяет:
- токенизацию
- валидацию
- парсинг
- форматирование

и предоставляет единый интерфейс конвертации.

---

# Интерфейс

GUI реализован на Qt.

Поддерживает:
- ввод числа
- выбор систем счисления
- отображение результата
- загрузку из `.txt`
- сохранение в `.txt`

# Особенности реализации

- длинная арифметика произвольной точности
- алгоритм Карацубы для быстрого умножения
- поиск периодов через hash map
- поддержка чисел длиной более 100000 символов
- оптимизированная работа со строками
